Mom Care by BillionTech

Privacy policy

Effective September 29, 2026

Nothing leaves the phone. Mom Care's protection works entirely on the device it is installed on. The app itself has no internet access, no accounts, no ads and no analytics, and it does not collect, sell or share any information. Subscriptions are handled by Google Play.

What Mom Care does

Mom Care is a parental control app for Android. A parent installs it on their child's phone. The child can watch any video in the official YouTube app, except: Shorts (if the parent blocks them), channels the parent has blocked, and videos whose title or channel name contains a word on the parent's blocked-words list. Mom Care can also block searching for those words, downloads and app-install buttons, ads and links that leave YouTube, and video-downloader apps on the parent's blocked list.

How Mom Care uses the Accessibility service

To work, Mom Care uses Android's Accessibility service. It is set up to observe only the YouTube app, common web browsers and app stores (only to notice that they opened right after a tap in YouTube), and, if the parent turns this on, the specific apps on the parent's blocked list. It does not observe any other app.

While YouTube is open, Mom Care reads what is shown on screen, such as video titles, channel names, whether the Shorts player is open, the label of a button that was tapped (for example "Download", "Install" or "Search"), and words typed in YouTube's search box. For browsers, app stores and apps on the blocked list, it only uses the fact that the app has opened; it does not read what is shown in them.

It uses this only to decide, on the phone, whether to allow or block what is happening. If something is not allowed, Mom Care pauses playback, leaves the screen or app and shows a friendly "not this one" message. After a video is blocked, it also checks whether YouTube is showing a small picture-in-picture window and keeps that video paused.

This information is processed in the phone's memory and then discarded. It is not saved and it is never sent anywhere. The parent is shown a clear explanation and must agree before the Accessibility service can be turned on.

Information stored on the phone

Mom Care saves only the settings the parent chooses, in the app's private storage on the device:

  • Which rules are turned on (Shorts, blocked words, search, downloads, ads and links, downloader apps).
  • The blocked-words list and the blocked-channels list the parent typed in.
  • The list of blocked apps (their package names), which the parent can edit.
  • The parent PIN and the PIN recovery code, each stored only as a protected, one-way code (a salted hash). The PIN and the recovery code themselves are never stored. The recovery code is shown once; if the parent chooses "Send to myself", it is shared only to the app the parent picks.
  • Advanced detection settings, if the parent changes them.
  • The date the free trial started and whether a subscription is active.

These settings are excluded from phone backups and are never uploaded.

Subscriptions and payments

Mom Care offers a 7-day free trial, then a subscription (monthly or yearly) sold through Google Play. Payments are processed by Google under the Google Payments Privacy Notice. Mom Care never sees your card or payment details.

To know whether protection should be on, Mom Care asks the Google Play app on the phone whether a subscription is active, and saves only the answer (active or not) and the date the free trial started. You can manage or cancel your subscription at any time in Google Play → Payments & subscriptions.

Diagnostics

A parent can turn on an optional diagnostics feature for testing. It keeps a copy of the last YouTube screen that Mom Care checked, so the parent can see what the app is able to read. This copy is held only in memory, is replaced with each new check and is erased when the app closes. It is only shared if the parent chooses to copy it themselves.

Children's privacy

Mom Care is meant to be set up and managed by a parent or guardian. It does not collect personal information from children or from anyone else, and it does not create any account or profile for the child.

Deleting your data

All Mom Care data stays on the phone. You can remove it at any time by clearing the app's storage in Android Settings or by uninstalling the app.

Changes to this policy

If a future version adds online features, such as a parent dashboard or syncing between devices, this policy will be updated first to explain exactly what is collected and why. The effective date above will change whenever the policy is updated.
